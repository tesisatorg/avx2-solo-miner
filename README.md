# avx2-solo-miner

**English** | [Türkçe](README.tr.md)

A hobby, **education-oriented** solo Bitcoin miner: PHP (Stratum v1 client and worker management) + C (8-way AVX2 SHA-256d scanner) + optional Overt AsicBoost (BIP 310 version rolling).

> **Honest expectations:** this software will not make you money. A laptop i7 reaches roughly 40-50 MH/s while the network is around 1 ZH/s. The chance of finding a block solo is practically zero (hundreds of millions of years). The goal is to see and learn how mining and its optimizations work (midstate, round elimination, AVX2, AsicBoost). Keep electricity cost and CPU heat in mind.

## Features
- Midstate precomputation, nonce entering at round 3, 61-round shortcut for the second hash, constant-folded message schedule
- AVX2: scans 8 nonces at once; every hit is re-verified with scalar code
- Overt AsicBoost: the second-chunk message schedule is shared across many block versions (~14% measured gain)
- `--selftest`: genesis block, merkle folding, nbits target and C kernel checks

## Setup
1. You need PHP 8+ (CLI) and GCC (MSYS2/MinGW on Windows).
2. Build:
   ```
   gcc -O3 -mavx2 -march=haswell -o sha256d_scan.exe sha256d_scan.c      # Windows
   gcc -O3 -mavx2 -march=haswell -o sha256d_scan sha256d_scan.c          # Linux
   ```
3. Copy `config.example.php` to `config.php` and put your own BTC address in it.
4. Verify: `php miner.php --selftest`
5. Run: `php miner.php` (all cores) or `php miner.php 6` (6 workers). Stop with Ctrl+C or by deleting `run.flag`.

Run it from the command line, not from a browser. Without the C kernel it falls back to a very slow pure-PHP mode.

## Heat and power
At full load the CPU can get very hot. On Windows, setting "Maximum processor state" to 99% disables turbo (about 20% slower, about 15 °C cooler). Using fewer workers than cores is another option.

## Pool
Default is `solo.ckpool.org:3333`. Your address is sent as the user name; if a block is found the reward goes directly to it. The pool's initial difficulty is high, so the miner asks for a lower one with `mining.suggest_difficulty`.

## Layout
- `miner.php`: Stratum client, worker processes, self-tests
- `sha256d_scan.c`: AVX2 + AsicBoost kernel (straight-line code generated by `tools/gen_ab.py`)
- `tools/`: kernel generator and template
- `tests/`: mock pool for end-to-end testing

## Responsibility
Use it only on your own hardware and with your own address. Running it on someone else's device without consent is illegal.
